# Leques – Meninas CEEC e Projeto Ninho

Modelo de leque produzido em MDF para os projetos **Meninas CEEC**, do IFG Câmpus Jataí, e **Projeto Ninho**, do IFG Câmpus Inhumas.

O projeto foi desenvolvido para a fabricação de leques personalizados, utilizando corte a laser e arquivos digitais que permitem a reprodução da peça.

## Arquivos disponíveis

- `.svg` – arquivo vetorial para visualização e edição do modelo.
- `.wcvr` – arquivo compatível com o software AutoLaser, utilizado para preparar e executar o corte nas máquinas a laser.
- `.png` – imagem ilustrativa do leque antes da fabricação.
- `.jpg` / `.jpeg` – fotografia do leque após a fabricação.

## Materiais e fabricação

- **Material:** MDF.
- **Processo de fabricação:** corte a laser.
- **Equipamento:** máquina de corte a laser compatível com o software AutoLaser.

## Créditos

Projeto desenvolvido no contexto das ações dos projetos **Meninas CEEC** e **Projeto Ninho**, vinculados ao Instituto Federal de Goiás (IFG), nos câmpus Jataí e Inhumas.

Os arquivos digitais podem ser utilizados como referência para a reprodução e adaptação do modelo, conforme as necessidades de cada projeto.
